# frontend/

Owned by the **frontend agent**. Brief: [`../agents/frontend.md`](../agents/frontend.md). API contract: [`../docs/contracts.md`](../docs/contracts.md).

Run:

```bash
npm install
npm run dev        # http://localhost:5173
```

Set `VITE_API_BASE` (default `http://localhost:8000`) and `VITE_USE_MOCK=true` to work without the backend.
