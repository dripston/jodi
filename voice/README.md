# voice/

Owned by the **voice agent**. Brief: [`../agents/voice.md`](../agents/voice.md).

This folder is the versioned copy of everything configured in the Sarvam Voice Agents dashboard:

- `agent.md`: agent settings (voice, language, variables, hooks, deployment, agent version)
- `prompts/`: system prompt and mode prompts
- `tools/`: API tool configurations (JSON, no secrets)
- `tests/`: test scenarios run in Sarvam Tests

Keep the dashboard and this folder in sync; mention the dashboard agent version in each commit message.
